# Web Build Implementation Plan

**Goal:** pygbag 웹 빌드와 GitHub Pages 자동 배포로 링크 하나로 플레이할 수 있게 하고, Hard 계산 중에도 화면이 멈추지 않게 하며, 휴대폰용 화면 버튼을 추가한다.

**Architecture:** 게임 루프는 `async def main()`으로 매 프레임 `await asyncio.sleep(0)`. Hard 탐색은 제너레이터(`move_steps`)로 바꿔 게임 화면이 프레임마다 12ms씩 진행한다. 빌드는 `tools/build_web.py` 하나로 로컬과 CI가 공유한다.

**Tech Stack:** Python 3.12, pygame 2.6, pygbag 0.9.3, GitHub Actions, GitHub Pages

**Spec:** `docs/design/2026-10-06-web-build-design.md`

## Global Constraints

- 브랜치 `feat/web-build`
- `board.py`, `ai.py`는 pygame을 import 하지 않는다
- 테스트는 프로젝트 루트에서 `.venv/bin/python -m pytest`
- 기존 `choose_move(board, color, level="normal", rand=None)`의 시그니처와 결과를 유지한다
- pygbag 빌드 옵션: `--build --title Omok --ume_block 0` (시제품 빌드로 확인. `--ume_block 0`은 클릭 없이 바로 시작)
- 커밋 메시지 영어, Conventional Commits
- **모든 커밋/푸시 전에 사용자 확인**

## Review Focus

1. 계산 중 무르기/다시/메뉴 버튼을 누르면 남은 계산 결과가 새 판에 놓이지 않는지 (Task 2 수동 확인, 기존 키 경로와 같은 처리)
2. 화면 버튼을 눌렀을 때 그 클릭으로 돌이 함께 놓이지 않는지 (Task 2 `bar_buttons` 테스트 + 클릭 처리 순서)
3. 분할 실행으로 바뀐 Hard가 기존과 같은 수를 두는지 (Task 1 테스트, 대국 테스트)
4. CI에서 pygame 테스트가 화면 없이 도는지 (`SDL_VIDEODRIVER=dummy`, Task 4)
5. PR에서는 배포하지 않고 main push에서만 배포하는지 (Task 4 워크플로 조건)

### Task 2: 비동기 루프, 분할 진행, 화면 버튼

**Files:** Modify `omok/game.py`, `main.py`; Test `tests/test_game.py`

**Interfaces:**
- Consumes: `move_steps` (Task 1)
- Produces: `advance(steps, budget_ms) -> tuple[bool, object]`, `bar_buttons() -> dict[str, pygame.Rect]` (키 `"무르기"`, `"다시"`, `"메뉴"`), `async def main()`. `run()`은 삭제

- [ ] **Step 1: 실패 테스트 추가**

```python
def test_advance_runs_at_least_once_and_finishes():
    from omok.game import advance

    def steps():
        yield
        yield
        return "done"

    gen, results = steps(), []
    while not results or not results[-1][0]:
        results.append(advance(gen, 0))
    assert results == [(False, None), (False, None), (True, "done")]

def test_bar_buttons_stay_above_board():
    from omok.game import bar_buttons
    buttons = bar_buttons()
    assert list(buttons) == ["무르기", "다시", "메뉴"]
    rects = list(buttons.values())
    for i, rect in enumerate(rects):
        assert rect.bottom < TOP and pixel_to_cell(*rect.center) is None
        assert not any(rect.colliderect(other) for other in rects[i + 1:])
```

- [ ] **Step 2:** `.venv/bin/python -m pytest tests/test_game.py -q` → FAIL (`ImportError`)
- [ ] **Step 3: 구현**
- `advance`: `end = time.perf_counter() + budget_ms / 1000`, `next()`를 반복하다 `StopIteration`이면 `(True, value)`, `next()` 후 시간이 지났으면 `(False, None)`
- `bar_buttons`: 64×30, 간격 8, 오른쪽 끝 `WIDTH - 16`, 세로 중심 `TOP // 2 - 4`
- 그리기: `draw_game`에서 기존 도움말 텍스트 대신 버튼. `pygame.draw.rect(screen, theme.text_color, rect, 2, border_radius=8)` + `theme.text(screen, label, 18, rect.center, "center", rough=.3)`. `HELP` 상수 삭제
- 동작: 무르기/다시/메뉴 처리를 루프 안 함수 `act(name)` 하나로 모으고, 키(`U`/`R`/`ESC`)와 버튼 클릭이 모두 이를 호출. `act`는 `ai_pending = False`, `ai_steps = None`부터 수행
- 클릭 처리 순서: `playing`/`over`에서 버튼 영역 클릭이면 `act` 후 끝 (돌 놓기로 넘어가지 않음), 아니면 기존 착수 처리
- AI: 착수 후 `ai_steps = move_steps(board, WHITE, level)`, `ai_move = None`, `ai_due` 설정. 그리기와 `flip` 뒤 `ai_move is None`이면 `done, value = advance(ai_steps, 12)`, `done`이면 `ai_move = value`. `ai_move`가 있고 `ai_due`가 지났으면 착수
- 기존 `pygame.event.clear(MOUSEBUTTONDOWN)`은 삭제 (계산이 프레임을 막지 않으므로 클릭은 `ai_pending` 검사로 걸러짐, 버튼은 눌려야 함)
- 루프를 `async def main()`으로, `clock.tick(60)` 뒤 `await asyncio.sleep(0)`
- `main.py`: `import asyncio`, `from omok.game import main`, `asyncio.run(main())`
- [ ] **Step 4:** `.venv/bin/python -m pytest -q` → 49 passed
- [ ] **Step 5: 수동 확인 (데스크톱)** — `.venv-win\Scripts\python main.py`: 버튼 3개 동작, Hard 계산 중 "생각 중" 점이 계속 움직이는지, 계산 중 [다시]를 누르면 빈 판에 AI 돌이 생기지 않는지

### Task 4: GitHub Actions와 README

**Files:** Create `.github/workflows/pages.yml`; Modify `README.md`

- [ ] **Step 1: 워크플로**

```yaml
name: Test, build and deploy
on:
  push:
    branches: [main]
  pull_request:
    branches: [main]
  workflow_dispatch:
permissions:
  contents: read
  pages: write
  id-token: write
concurrency:
  group: pages
  cancel-in-progress: false
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - run: pip install -r requirements.txt
      - run: python -m pytest
        env:
          SDL_VIDEODRIVER: dummy
  build:
    needs: test
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - run: pip install -r requirements-dev.txt
      - run: python tools/build_web.py
      - uses: actions/upload-pages-artifact@v3
        with:
          path: dist/omokgame/build/web
  deploy:
    if: github.event_name != 'pull_request'
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - id: deployment
        uses: actions/deploy-pages@v4
```
